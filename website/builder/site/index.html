ตัวเลข

สิ่งที่แก้ได้

30สินค้าทุกชิ้นบนเว็บ
6ชื่อ ราคา ประโยคขาย ขนาด ซ่อน หมด
1ประกาศออกบูธ ตั้งวันปิดเองได้
5–10นาที กดแล้วเว็บเปลี่ยน
  • เปลี่ยนชื่อ ราคา หรือประโยคขาย Claude ทำโปสเตอร์ของสินค้านั้นใหม่ให้ด้วย (ทดสอบแล้ว ภาพเหมือนเดิมทุกพิกเซลยกเว้นตรงที่แก้)
  • “หมดชั่วคราว” ยังโชว์สินค้าบนเว็บ แต่ขึ้นป้ายหมด และข้อความสั่งซื้อเปลี่ยนเป็นขอสั่งจองรอบหน้า
  • ราคาเก็บที่เดียวใน brand.py แผนบูธและโปสเตอร์จึงใช้ราคาเดียวกับเว็บ
  • ร่างแก้ได้เฉพาะเจ้าของร้านและคนที่แชร์ให้เป็น Editor คนอื่นดูได้อย่างเดียว
ต้องทำก่อนใช้ปุ่มขึ้นเว็บ

รวมงานนี้เข้า main หนึ่งครั้ง ตอนนี้งานอยู่ในกิ่ง claude/funny-tesla-4dkwm7 ปุ่มขึ้นเว็บเปิด Claude บน main จึงต้องมีไฟล์ชุดนี้ก่อน บอก Claude ว่า “รวมเข้า main” หรือเปิด PR แล้วกด Merge

ครั้งแรกที่กดขึ้นเว็บ claude.ai จะขอให้อนุญาตหน้านี้ใช้ Claude Code Remote กดอนุญาตครั้งเดียว

ไฟล์

อยู่ที่ไหน

  • website/builder/index.html หน้า Web Builder (สร้างจาก build.py)
  • website/builder/apply.py ตรวจค่าที่แก้ แล้วแก้ brand.py กับ website/build.py ทำโปสเตอร์และเว็บใหม่
  • website/builder/APPLY.md ขั้นตอนที่ Claude ทำเมื่อกดขึ้นเว็บ
  • website/builder/live.json ค่าที่เว็บโชว์ตอนนี้
  • website/build.py เพิ่มป้าย “หมดชั่วคราว” (ชุด SOLD) บนหน้าแรกและหน้าสินค้า
  • website/builder/site/ หน้าสรุปนี้
ลองดู

สิ่งที่ควรเช็ก

  1. เปิด Web Builder บนมือถือ แตะสินค้าสักชิ้น ลองเปลี่ยนราคา แล้วดูว่าแถบล่างขึ้น “แก้ไว้ 1 อย่าง”
  2. กด “ตรวจแล้วขึ้นเว็บ” ดูรายการ ถ้ายังไม่อยากขึ้นจริง กด “ล้างร่างทั้งหมด”
  3. หลังรวมเข้า main แล้ว ลองขึ้นเว็บจริงหนึ่งครั้ง เช่น ตั้ง “หมดชั่วคราว” ให้สินค้าที่หมดจริงที่บูธ
ต่อไป

เพิ่มได้อีก

  • เพิ่มสินค้าใหม่หรือเปลี่ยนรูปสินค้าจากหน้านี้
  • แก้วิธีต่อ (steps) และ “เหมาะกับ”
  • สลับลำดับสินค้าบนหน้าแรก
