ทำอะไรได้

แก้ได้ทุกอย่างที่ขึ้นเว็บ

  • สถานะ: ขายอยู่ · ของหมด (หน้ายังอยู่ ปุ่มเปลี่ยนเป็นถามรอบหน้า) · ซ่อน (ไม่ขึ้นเว็บ ลิงก์เดิมพาไปหน้าแรก)
  • ชื่อ ราคา ขนาด ข้อความ "ใช้ทำอะไรได้" ลำดับรูป และเพิ่มรูปจากมือถือ
  • ชื่อสำหรับค้นหา มีตัวอย่างหน้าตาใน Google ให้ดู
  • ลิงก์ร้าน Shopee: ใส่แล้วปุ่ม Shopee ขึ้นทุกหน้า · ข้อความบูธและวันที่ประกาศหาย
  • ขอเพิ่มสินค้าใหม่ (ชิ้นเดียว) พร้อมรูปและรหัส
  • คำต้องห้ามตามเอกสารสถานะขึ้นแดงและส่งไม่ได้ เว็บก็ตรวจซ้ำอีกรอบก่อนสร้าง
  • ร่างบันทึกทันที เปิดจากมือถือหรือคอมก็เห็นเหมือนกัน แก้ได้เฉพาะคุณและคนที่ได้สิทธิ์ Editor
ต้องทำ

ก่อนใช้ครั้งแรก

  1. กด Merge PR #5 ก่อน เพราะ Claude อ่านขั้นตอนจาก main (หน้าเว็บวันนี้หน้าตาเหมือนเดิม)
  2. เปิดหน้าจัดการสินค้า ลองแก้ราคาสักชิ้น ดูว่าขึ้นในแท็บ "ส่งขึ้นเว็บ" แล้วกด "คืนค่าเดิม" ได้
  3. ครั้งแรกที่กดส่ง claude.ai จะถามว่าให้หน้านี้สั่ง Claude Code ได้ไหม ให้กดอนุญาต
  4. ถ้าให้คนอื่นช่วยแก้ แชร์หน้านี้จากเมนู Share แบบ Editor
